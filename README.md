# Ochlos

OSI L3~L7 계층별 네트워크 공격 기법(DoS/DDoS)을 C++20으로 직접 구현하고, 격리된 Docker 테스트베드 환경에서 그 메커니즘과 방어선(Hardening)의 유효성을 실증하는 레드팀 시뮬레이션 학습 프로젝트입니다.

정보보안기사 국가기술자격 및 KISA 주요정보통신기반시설 기술적 취약점 분석·평가 기준을 참고하여, 패킷 구조(체크섬, 헤더 조작 등)와 공격 메커니즘을 원리 수준에서 학습하는 것을 목표로 합니다.

## 구성

- `DoS/` — L3/L4 계층 공격 실증 코드 (ICMP Echo Flooding, Raw TCP SYN Flooding, Raw UDP Flooding)
- `include/` — 공통 패킷 조립/체크섬 유틸리티 (`ochlos_net.hpp`)
- `CLAUDE.md` — 프로젝트 개요 및 협업 규칙
- `docs/ATTACK_LOG.md` — 공격 실증 이력 (시나리오별 계측 결과)
- `docs/TODO.md` — 공격 도구·실행 인프라 백로그

## 요구 사항

- C++20 지원 컴파일러 (MSVC / Apple Clang / GCC)
- CMake 3.15 이상
- Raw Socket 사용을 위한 관리자 권한 또는 `CAP_NET_RAW` 권한 (Docker 컨테이너 내부 실행 권장)
